# Security

## Supported versions

Fixes go into the newest release. Please update before you report.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use **Report a vulnerability** on the
[Security tab](https://github.com/MojiX-Tech/Automation/security/advisories/new) of this
repository. The report is private. You get an answer within a week, and credit in the release
notes if you want it.

Helpful in a report: the role, its version, the OS of the target, what an attacker can do and
how to reproduce it.
